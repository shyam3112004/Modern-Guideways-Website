# Modern Guideways — Complete Website Project Brief

## Executive summary
Create a premium industrial website for Modern Guideways with five individually animated navigation destinations and a six-scene horizontal Products experience. Preserve the existing hero frame-sequence animation if it is verified in the project. Use a Metallic Blue industrial design system, genuine company assets and direct enquiry paths.

## Primary destinations
1. Overview — brand introduction and cinematic machinery hero.
2. Products — six product scenes with individual reveal transitions.
3. Gallery — genuine product/workshop imagery with staggered editorial reveal.
4. About Us — verified company story and animated engineering timeline.
5. Contact — direct call/email/directions and approved RFQ actions.

## Animation requirement
Each main navigation destination has its own animation signature. The Products destination must not resolve to a static three-column grid on desktop. It should display one prominent product scene at a time in a horizontal track with individual transitions for telescopic covers, roller covers, apron covers, bellows, guide wipers and enclosing guards.

## Brand and build constraints
Metallic Blue/deep navy/graphite/steel-grey. Maintain logo. Static-first. No unnecessary paid services, database or payment gateway. Respect reduced motion and mobile touch behavior.

## Gate structure
G1 discovery/assets; G2 design system; G3 animation proof; G4 core build; G5 content/assets; G6 QA/release readiness; G7 production deployment.

## Scope boundary
This is a planning specification. It does not certify that the current local website already implements these experiences. Runtime behavior must be demonstrated in the browser.
