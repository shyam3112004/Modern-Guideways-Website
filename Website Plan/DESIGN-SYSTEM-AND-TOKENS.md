# Design System and Token Plan

## Color
Use the owner-approved logo as source. Previously sampled candidates: Metallic Blue #002D71, Primary Blue #00459E, Highlight #6874D4. Verify contrast for each foreground/background pair.

## Typography
Previous direction: Outfit headings + Plus Jakarta Sans body. Verify license/font loading and use local/system fallbacks. Keep large type readable on mobile.

## Geometry
4px base spacing scale; shared container widths; consistent control heights; restrained radii; sharp/technical borders for industrial panels.

## Surfaces
Alternate deep navy/graphite feature surfaces with light neutral informational surfaces. Avoid dark-gradient-everywhere.

## Motion tokens
Define duration/ease tokens: micro feedback, nav transition, content reveal and product sequence. Keep easing consistent and support reduced motion.

## Deliverable
Single source of truth in CSS variables, plus component variants and a contrast table.
