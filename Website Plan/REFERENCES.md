# Design and Technical References

This plan uses the following current public references to inform the motion direction. These are external references, not evidence that a particular animation is suitable until it is tested in this project.

1. Figma, *Top Web Design Trends for 2026* — immersive elements, experimental navigation and evolving visual patterns: https://www.figma.com/resource-library/web-design-trends/
2. GSAP, *ScrollTrigger documentation* — pin, scrub, snap, responsive matchMedia and refresh behavior: https://gsap.com/docs/v3/Plugins/ScrollTrigger/
3. MDN, *prefers-reduced-motion* — detecting user preference and reducing/replacing nonessential movement: https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion
4. MDN, *Using media queries for accessibility* — reduced-motion implementation guidance: https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Media_queries/Using_for_accessibility
5. MotionKit, *Web Animation Trends 2026* — scrollytelling, kinetic typography, scroll-driven effects and performance/accessibility discussion: https://motionkit.io/blog/web-animation-trends-2026

## Applied interpretation
Adopt visual storytelling, distinctive navigation transitions, product-specific reveal motion, editorial typography and useful micro-interactions. Avoid adopting every trend. The manufacturing site should prioritize product comprehension, trust, access to specifications and enquiry conversion over spectacle.
