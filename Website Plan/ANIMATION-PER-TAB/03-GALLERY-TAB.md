# Tab Animation 03 — Gallery

## Signature motion: Editorial image reveal
**Trend-informed pattern:** staggered editorial reveals, image masking and restrained hover feedback.

### Entry sequence
- Section title reveals with a short upward mask.
- Main feature image clips into view from one edge.
- Secondary images enter in a controlled 80–120ms stagger.
- Caption labels fade/slide by a few pixels.
- Hover can scale image slightly (around 1.02–1.04) and reveal caption contrast.

### Interaction
Click opens the existing accessible Lightbox if present. The Lightbox must trap focus, close on Escape, support previous/next and restore focus to the trigger.

### Asset rules
Only genuine, approved workshop/product images. No generated imagery or stock image should be represented as company work. Include caption/alt-text content.

### Acceptance
Stagger does not change layout after load; no image is stretched; keyboard users can reach and open items; reduced motion displays the same gallery without animated reveal.
