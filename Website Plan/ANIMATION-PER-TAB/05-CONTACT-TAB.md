# Tab Animation 05 — Contact

## Signature motion: Contact rails and action feedback
**Trend-informed pattern:** purposeful micro-interactions and motion-assisted feedback.

### Entry sequence
- Heading appears with short line reveal.
- Phone/email/address rows enter with a small stagger.
- A fine accent rule draws under the active contact row.
- CTA arrow shifts slightly on hover/focus.

### Interaction
- `tel:` opens the dialer on supported devices.
- `mailto:` opens the visitor's email client.
- WhatsApp action only appears after number is verified as WhatsApp-enabled.
- Directions open a verified address in an external map.
- RFQ flow uses the existing modal/structured message payload; no false "sent" success if the message is merely prefilled.

### Acceptance
Every contact link is correct; focus/hover feedback is visible; small screens wrap safely; reduced motion leaves all actions fully functional.
