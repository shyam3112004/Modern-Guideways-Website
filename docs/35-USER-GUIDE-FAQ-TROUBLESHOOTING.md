**Version:** 1.0

## 1. Purpose
Visitors scroll to explore and use product links or contact actions to reach the company.

## 2. Project context
If the story is slow, wait for the initial keyframes; if motion is reduced, a poster is shown.

## 3. Requirements and implementation
Maintainers run npm install, npm run dev, npm run build and deploy dist/.

## 4. Scope boundaries and risks
Enquiries open the the visitor email or WhatsApp application; site does not store them.

## 5. Acceptance criteria
A new maintainer can start, preview, build and deploy using this guide.

## 6. Dependencies and open items
- Confirm company-approved brand assets, business facts and content before public launch.
