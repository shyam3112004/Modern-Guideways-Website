# 04 — UI/UX Design Brief

**Project:** Modern Guideways Website  
**Version:** 1.0  
**Status:** Starter — owner review required  
**Last updated:** 2026-11-07  
**Owner:** TBD

## 1. Purpose
Industrial luxury: deep navy, steel-grey, white and restrained indigo; precise grid, editorial type and purposeful motion.

## 2. Project context
Design should feel credible to industrial buyers, not like a generic AI template.

## 3. Requirements and implementation
Typography: Manrope + DM Mono with Georgia italic display accents. Spacious layouts, sharp geometry, restrained borders.

## 4. Scope boundaries and risks
Use company-approved logo and real product photography when supplied.

## 5. Acceptance criteria
Desktop and mobile visual review approved by company owner.
