# 26 — Accessibility Standard

**Project:** Modern Guideways Website  
**Version:** 1.0  
**Status:** Starter — owner review required  
**Last updated:** 2026-11-07  
**Owner:** TBD

## 1. Purpose
Use semantic landmarks, descriptive links, visible focus, alt text and reduced-motion fallback.

## 2. Project context
Canvas is decorative storytelling; equivalent headline and description are available as HTML.

## 3. Requirements and implementation
Check keyboard navigation, contrast, zoom, screen reader order and motion preferences.

## 4. Scope boundaries and risks
Canvas frame detail is not a substitute for meaningful HTML content.

## 5. Acceptance criteria
Core navigation and contact actions work by keyboard; reduced-motion mode is usable.

## 6. Dependencies and open items
- Confirm company-approved brand assets, business facts and content before public launch.
