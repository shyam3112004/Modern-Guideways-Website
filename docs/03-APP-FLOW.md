**Project:** Modern Guideways Website  
**Version:** 1.0  
**Status:** Starter — owner review required

## 1. Purpose
Visitor journey: land on story → explore company → browse products → understand capabilities → inspect visual story → contact.

## 2. Project context
Primary conversion routes are WhatsApp, phone and email.

## 3. Requirements and implementation
Header anchors: Company, Products, Capabilities, Gallery, Contact.

## 4. Scope boundaries and risks
No user login or gated journey.

## 5. Acceptance criteria
Every navigation anchor reaches a valid section; contact CTA is available from header and page end.
