# 10 — Content Editor Guide

**Project:** Modern Guideways Website  
**Version:** 1.0  
**Status:** Starter — owner review required  
**Last updated:** 2026-11-07  
**Owner:** TBD

## 1. Purpose
Edit source text in index.html and style.css. Product descriptions live in product card markup.

## 2. Project context
Do not invent specifications, materials, warranties, certifications or customers.

## 3. Requirements and implementation
Use a code editor, commit changes, run build, preview and deploy.

## 4. Scope boundaries and risks
No CMS/editor account in v1.

## 5. Acceptance criteria
A content change can be reviewed locally and deployed without changing the animation pipeline.

## 6. Dependencies and open items
- Confirm company-approved brand assets, business facts and content before public launch.
